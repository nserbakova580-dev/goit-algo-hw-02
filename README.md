# HW4: Порівняння алгоритмів сортування

## Algorithms
- Insertion Sort
- Merge Sort
- Timsort (sorted, sort)

## Datasets
- sorted
- almost sorted
- random
- reverse
- runs

## Conclusion
Timsort демонструє найкращий баланс між швидкодією, використанням пам’яті та адаптивністю до структури даних. Merge Sort забезпечує стабільну продуктивність, але є більш пам’яттєвитратним. Insertion Sort ефективний лише на малих або майже відсортованих наборах даних.
